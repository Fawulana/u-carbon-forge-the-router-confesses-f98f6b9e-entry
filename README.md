Entry for the [make.fun bounty "The Router Confesses"](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e): a home Wi-Fi router's one-line excuse for dropping the connection at the exact climax of a movie.

## The line

> I didn't drop the connection — I hid the ending because I saw the twist first, and I wanted to enjoy it alone.

Why this line: instead of the usual buffering/bandwidth apology, the router confesses a petty, smug little secret — it peeked at the twist and kept the ending for itself out of jealousy. It speaks in the router's own voice, lands in one breath, and the twist (the router as a spoiler-hoarding viewer, not a broken appliance) is the joke.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (creating `/output` if needed). Deterministic, offline, standard library only — the same bytes on every run. The program validates the gate itself before writing: 1–200 characters, a single line, not whitespace-only.
